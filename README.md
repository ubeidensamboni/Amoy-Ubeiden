# Wedding Website – Status: Hitched! 📨

If you're reading this—hello! We didn’t want to spend money on Squarespace, Wix, or similar platforms to make a wedding website for our guests, so here it is, deployed on GitHub Pages.

## Inspiration

I took heavy inspiration from GitHub repositories like [walice/wedding-template](https://github.com/walice/wedding-template) and [Emanuele-Sgroi/My-Wedding-Invitation-Website](https://github.com/Emanuele-Sgroi/My-Wedding-Invitation-Website).

I copied a repo to get started and created my own version, blending ideas from multiple sources.

## Deployment

This site is deployed using GitHub Actions' free tier, following [this guide](https://gohugo.io/hosting-and-deployment/hosting-on-github/).
